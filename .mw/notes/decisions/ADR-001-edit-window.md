# ADR-001: Status edit window

- Date: 2026-10-01
- Status: Superseded on 2026-11-10 by the baseline gate (conflict CF-001 in `.mw/runs/BASELINE-2026-10-30/baseline-review-report.json`). The edit window is 60 minutes, as the code enforces.

## Decision

Users may edit a status for 30 minutes after posting. After that it is final.

## Reason

Long edit windows let people change a post after others have replied to it.
