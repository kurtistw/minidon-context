# Flow Mapping

Draw user journeys and the value stream for the affected capabilities

## Usage

Write `research/flows/journeys.md` and `research/flows/value-stream.md` as Mermaid so they diff in git.
Cite discovery capabilities by id. In the value stream, mark process and wait times where known and say where they are not.
A prototype is optional, disposable and never the spec.
